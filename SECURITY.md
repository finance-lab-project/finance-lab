# Reporting a security issue

Report a suspected vulnerability through [GitHub’s private reporting form](https://github.com/finance-lab-project/finance-lab/security/advisories/new). The repository maintainers can use the report to investigate and discuss a fix privately.

Include the affected release tag or commit, the feature involved, what you observed and what you expected to happen. If an example helps, use a disposable local demo account and synthetic ruble amounts. Keep passwords, tokens, personal budget data and database backups out of the report.

The [release history](https://github.com/finance-lab-project/finance-lab/releases) identifies published builds and their verification details. For ordinary bugs and feature requests, use [GitHub Issues](https://github.com/finance-lab-project/finance-lab/issues).
